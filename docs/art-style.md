# «Сплав» — стиль графики (ART-01, ART-02)

Один стиль для всего: поля, деревни, иконок, промо. Плоская иллюстрация «детская книжка о летней деревне у реки»: тёплая палитра, мягкие тени, скруглённые формы, тёмный контур. Ни одного «голого» геометрического примитива: у каждого предмета есть форма, объём (светлая и тёмная сторона), блик и тень на земле.

## Правила рисования

- **SVG вручную**, без растровых вставок, без `<text>` (шрифтов при растеризации нет), без фильтров (`filter`, `feGaussianBlur`) — их плохо и медленно рисуют resvg и браузеры на телефонах. Разрешены `linearGradient`, `radialGradient`, `clipPath`, `opacity`.
- **Свет сверху слева.** Тёмная сторона — справа снизу.
- **Объём в три слоя**: основная заливка → тень (тот же цвет на 15–25 % темнее, отдельная фигура по правому нижнему краю, без контура) → блик (белый 35–55 % непрозрачности, скруглённая полоска или пятно сверху слева, без контура). Можно мягкий градиент сверху вниз (светлее → темнее) вместо отдельной тени.
- **Контур** — `stroke-linejoin="round"`, `stroke-linecap="round"`. Толщина для спрайтов 128×128 — `6` (на экране это 2,5–3 px). Внутренние линии (прожилки, доски, чешуя) — `3–4`, тем же цветом контура или на 30 % светлее заливки.
- **Цвета контура** (только тёмно-зелёный или коричневый, ART-01):
  - дерево, камень, постройки, люди — коричневый `#4a2f1b`;
  - растения, трава — тёмно-зелёный `#24432c`;
  - рыбы и вода — глубокий сине-зелёный `#1d4a4f`.
- **Тень на земле** — эллипс под предметом, `#1d3b2a`, непрозрачность `0.18`, без контура.
- Скругления везде: углы досок, крыш, камней.

## Спрайты поля (`art/sprites/*.svg`)

- `viewBox="0 0 128 128"`, `width="128" height="128"`. Предмет по центру, точка опоры — около `y = 104`; эллипс тени — по центру низа (`cy ≈ 108`).
- Поля 6 единиц со всех сторон: ничего не выходит за `6…122`.
- **Рост с уровнем** (ACC-01): предмет 1-го уровня занимает ~55 % клетки, 6-го — ~92 %. У 6-го уровня — золотой акцент (искорки, ободок).
- **Силуэт и цвет цепочки** различимы без цвета (ACC-01, дальтоники): дерево — вытянутые коричневые формы; сад — цветы с розовым и зелёным; камень — округлые серые глыбы; рыбалка — синие рыбы; волшебная капля — голубая капля с золотой звездой (без радуги: владелец запретил радужные мотивы).
- Цифра уровня в спрайт **не** рисуется — игра добавляет значок сама.
- Имя файла = имя кадра: `item-<цепочка>-<уровень>.svg`, `item-joker-0.svg`, `resident-<id>.svg`, `rock.svg`, `snag.svg`, `pier.svg`, `fx-*.svg`.

## Деревня (`art/village/*.svg`)

- Иллюстрация в DOM, сцена `viewBox="0 0 360 490"` (та же сетка, что у карты уровней: ряды кружков уровней на `y ≈ 122, 278, 434`, река змейкой по этим рядам; постройки над рядами — см. `src/ui/village-art.ts`).
- Постройки: `viewBox="0 -8 84 72"`, два состояния: **заброшенная** (серо-бурая палитра, проломленная крыша, доски крест-накрест, мох и сорная трава, покосившиеся элементы) и **восстановленная** (тёплые цвета, целая крыша, окна со светом, цветы, дым из трубы, флажки).

## Иконки интерфейса (`art/ui/*.svg`)

- `viewBox="0 0 24 24"`. Монохромные — заливка `currentColor` (пауза, настройки, книга, кубок, замок, видео); цветные — монета, звезда, сердце, бустеры — с контуром `#4a2f1b` толщиной `1.6` и бликом.
