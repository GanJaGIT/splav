## Решения

<!-- Дата — решение — почему. Сюда же — изменения баланса относительно ТЗ. -->

- 2026-10-11 — Образец: по просьбе владельца как пример готового результата используется его игра `Desktop\factory` («Сладкий конвейер», тот же стек и формат ТЗ, дошла до релизного пакета). Из неё взяты проверенные решения инфраструктуры (ниже отмечены «как в factory»); код игры пишется заново под ТЗ «Сплава».
- 2026-10-11 — TypeScript 6.0.3, а не 7.0: typescript-eslint 8.71 поддерживает TypeScript только до 6.1.
- 2026-10-11 — QA-03 (как в factory): браузеры Playwright лежат в `~/.cache/ms-playwright` (`scripts/browsers-path.ts`, установка — `npm run e2e:install`). Путь по умолчанию `%LOCALAPPDATA%\ms-playwright` ломается внутри упакованного приложения Claude: Firefox не запускается («side-by-side configuration is incorrect», не находится сборка `mozglue`). Проверено: тот же Firefox из другой папки запускается.
- 2026-10-11 — QA-03 (как в factory): e2e идут на e2e-сборке (`vite build --mode e2e` → `dist-e2e/`, `vite preview`), то есть на релизном коде плюс хуки DEV-02 (`__DEV_HOOKS__`). В релизной сборке хуков нет — это проверяет `check:build`. 3 воркера, без трассировки: WebGL в тестах программный.
- 2026-10-11 — QA-03 (как в factory): смоук строгий — провал при любом `error` и `warning` в консоли. Для этого: Chromium в тестах с `--use-angle=swiftshader` (иначе сам браузер пишет «GPU stall due to ReadPixels»); плагин сборки `splav-patch-phaser-typed-uploads` выключает у Phaser 4.2.1 флаги premultiply/flip-Y для загрузки текстур из `Uint8Array` (Firefox предупреждает о них; для таких данных флаги ничего не меняют; при смене версии Phaser сборка упадёт, и патч надо пересмотреть). Phaser исключён из `optimizeDeps`, чтобы патч работал и в `npm run dev`.
- 2026-10-11 — YG-01 (как в factory): `<script src="/sdk.js">` всегда в `index.html`. В `npm run dev` и `vite preview` его отдаёт плагин Vite пустой заглушкой (без 404 в консоли); в `dev:yg` и на платформе — настоящий SDK.
- 2026-10-11 — TECH-04, BLD-03: Phaser держит в коде адрес `https://phaser.io` для баннера в консоли (баннер выключен). Плагин сборки вырезает адрес, чтобы в архиве не было внешних ссылок.
- 2026-10-11 — UI-01: язык экрана загрузки угадывает маленький внешний скрипт `public/boot.js` (`?lang` или язык браузера) до загрузки игры; окончательный язык — от платформы (YG-06). Внешний, а не встроенный `<script>`, — на случай, если CSP Яндекса запрещает встроенные скрипты. Проверить с `sdk-dev-proxy --csp` на Этапе 4.
- 2026-10-11 — UI-13: ограничение активной области 1:2…2:1 применяется только на компьютере (так в ТЗ: «Компьютер: …»). Телефон всегда использует весь экран, иначе на вытянутых экранах (390×844) появлялись бы поля.
- 2026-10-11 — SND-03, YG-05 (как в factory): звук Phaser выключен (`audio: { noAudio: true }`) — Phaser создаёт AudioContext до касания, браузеры предупреждают. Звук будет у `AudioService`.
- 2026-10-11 — DEV-01: подписи на оверлеях `LocalPlatform` (заглушки рекламы и покупок) — английские строки в коде, не i18n: это не интерфейс игры, а имитация окон платформы для разработки.
- 2026-10-11 — До Этапа 4 игра всегда работает на `LocalPlatform` (и в сборке тоже); на Этапе 4 появится выбор «загружен `YaGames` → `YandexPlatform`».
- 2026-10-11 — `purchases-catalog.json` не создан: покупки — Этап 4 (YG-14). `LocalPlatform` без файла возвращает пустой каталог.

## Известные проблемы

<!-- Проблема — как воспроизвести — план. -->
