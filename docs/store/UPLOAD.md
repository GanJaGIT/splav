# «Сплав» 0.1.1 — загрузка в Яндекс Игры

Всё нужное лежит в этой папке. Порядок — как в консоли разработчика (https://games.yandex.ru/console).

## Файлы

| Файл | Куда |
|---|---|
| `splav-0.1.1.zip` | Черновик → «Архив с игрой» |
| `draft-ru.md`, `draft-en.md` | Тексты для каждого языка (название, описания, «Как играть», ключевые слова, теги, категории) |
| `icon-512.png` | Иконка (одна на оба языка) |
| `cover-ru-800x470.png`, `cover-en-800x470.png` | Обложка своего языка |
| `hero-1560x520.png` | Обложка для витрины (необязательно) |
| `screens/ru/…`, `screens/en/…` | Скриншоты своего языка: `desktop-1..4.png` (1920×1080) и `mobile-1..4.png` (1080×1920) |
| `video-16x9-ru.mp4`, `video-16x9-en.mp4` | Видео своего языка (16:9, до 28 с, в конце — название игры этого языка) |
| `video-9x16-ru.mp4`, `video-9x16-en.mp4` | Вертикальное видео для телефона (9:16), если в форме есть поле для него |
| `CREDITS.md` (в корне проекта) | Для себя: все ресурсы и лицензии |

## Шаги

1. **Черновик.** Откройте игру «Сплав» в консоли → «Черновик». Загрузите `splav-0.1.1.zip` (в архиве `index.html` в корне).
2. **Платформы:** компьютер, телефоны iOS и Android. ТВ не отмечать. Ориентация — **портретная**.
3. **Языки:** русский и английский. Возрастной рейтинг — **0+**.
4. **Отметить «Игра использует облачные сохранения».** Включить **автоматический полноэкранный режим** на телефоне.
5. **Тексты.** Для каждого языка скопируйте поля из `draft-ru.md` / `draft-en.md` (заголовки с числом символов не копировать). Теги и категории выберите из списков консоли по тем же названиям; если точного тега нет — ближайший по смыслу.
6. **Материалы.** Для каждого языка — **только свои файлы** (название на обложке и в конце видео должно совпадать с названием в черновике языка, п. 5.1.3): иконка `icon-512.png` (общая), обложка `cover-<язык>-800x470.png`, 4 скриншота компьютера и 4 телефона из `screens/<язык>/`, видео `video-16x9-<язык>.mp4` (и `video-9x16-<язык>.mp4`, если форма его принимает).
7. **Реклама** → Sticky-баннеры: на телефоне — внизу (портрет), на компьютере — включить; включить **«Использовать API для показа sticky-баннера»** (иначе баннер появится и в уровне).
8. **Рейтинги** (если ещё не созданы на Этапе 4): два числовых рейтинга по убыванию с техническими названиями `stars` и `daily`.
9. **Покупки:** в игре выключены (`features.iap = false`) — в консоли не должно быть активных товаров.
10. **Почта для обратной связи:** ваш адрес для игроков и модерации.
11. **Комментарий для модератора** — вставить текст:

> Прогресс сохраняется локально и в облаке сразу после каждого действия (пройденный уровень, монеты, постройки, настройки). Уровень длится 2–4 минуты; если перезагрузить страницу посреди уровня, игра откроет деревню, а незаконченный уровень нужно начать заново — так задумано, пройденные уровни, монеты и постройки сохраняются. Полноэкранная реклама показывается только после нажатия «Дальше» или «В деревню» в окне «Уровень пройден», начиная с 6-го уровня, не чаще раза в 3 минуты и не сразу после досмотренного видео за награду. Видео за награду — только по кнопкам со значком видео. При сворачивании вкладки, потере фокуса и во время рекламы игра встаёт на паузу и звук выключается; если игрок ушёл во время рекламы, после неё открыто окно «Пауза». Стики-баннер показывается только в деревне.

12. **Проверка черновика.** Откройте черновик с параметром `&debug-mode=16` в адресе:
    - индикатор загрузчика — `IT`, «Game Ready» зелёный;
    - пройдите уровни 1–6: звук есть после первого касания, при сворачивании вкладки звук пропадает и открывается «Пауза»;
    - индикатор геймплея зелёный в уровне и красный в паузе, окнах и деревне;
    - после 6-го уровня нажмите «Дальше» — полноэкранная реклама начинается без заметной задержки;
    - в деревне есть баннер, в уровне — нет;
    - проверьте то же на телефоне.
13. **Отправить на модерацию.**

Если модерация вернёт замечания — пришлите их текст, я исправлю и соберу новую версию.
