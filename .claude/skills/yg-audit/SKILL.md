# Аудит по требованиям Яндекс Игр

Цель — найти всё, из-за чего модерация откажет, и исправить это до отправки. Одна попытка модерации — 3–5 рабочих дней.

Раздел для проверки: `$ARGUMENTS` (пусто или `all` — всё).

## Порядок

1. Открой https://yandex.ru/dev/games/doc/ru/concepts/requirements.md и сверь «Дату последнего изменения» с редакцией в приложении A `docs/TZ.md` (29 сентября 2026). Если требования изменились — найди новые пункты и добавь их в отчёт отдельным блоком.
2. Запусти `npm run verify`. Если есть ошибки — сначала исправь.
3. Пройди чек-лист ниже. Для каждого пункта укажи статус и доказательство: тест (файл и название), скриншот (путь — и посмотри его), строка кода или вывод команды. Если проверить можно только в консоли Яндекса — статус «владелец» и что именно ему проверить.
4. Исправь всё, что исправляется кодом, и пройди затронутые пункты ещё раз.
5. Сохрани отчёт в `release/audit-<ГГГГ-ММ-ДД>.md`: таблица «Пункт | Статус | Доказательство | Что сделать», итог — число ✅, ⚠️, ❌ и пунктов для владельца.

Статусы: ✅ выполнено, ⚠️ риск, ❌ нарушение, 👤 проверяет владелец в черновике.

## Чек-лист

### sdk — сборка, SDK, сохранения

- [ ] `npm run check:build`: `index.html` в корне, распакованный размер до 100 МБ, имена файлов латиницей без пробелов (п. 1.21, 1.22).
- [ ] `/sdk.js` подключён относительным путём до кода игры; в `dist/` нет ссылок на S3 Яндекса (п. 1.7, 1.19.1).
- [ ] `YaGames.init()` вызывается один раз, остальные методы — после него (п. 1.19.1).
- [ ] `LoadingAPI.ready()` — ровно один раз, после отрисовки первого интерактивного экрана (п. 1.19.2).
- [ ] `GameplayAPI.start()` и `stop()` соответствуют реальному состоянию, без повторов подряд (п. 1.19.3).
- [ ] `game_api_pause` и `game_api_resume`: тишина, пауза, `stop`/`start` по правилам YG-04 (п. 1.19.4).
- [ ] Звук выключается при `blur`, `visibilitychange`, `pagehide` и на время рекламы (п. 1.3, 4.7).
- [ ] Игра работает без входа; вход только по кнопке с объяснением выгоды; прогресс гостя сохраняется (п. 1.2).
- [ ] Прогресс сохраняется сразу после действия и переживает перезагрузку и поворот экрана (п. 1.9).
- [ ] В UPLOAD.md есть шаг «отметить облачные сохранения» (п. 1.11).
- [ ] В консоли браузера нет ошибок (п. 1.14, 6.4).
- [ ] Игра работает по любому адресу, все пути относительные (п. 1.18).
- [ ] Нет интерактивного ИИ (п. 1.23).
- [ ] Нет внешних ссылок и запросов, упоминаний других площадок (п. 8.4): поиск `http` по `dist/`, разрешена только Метрика.

### devices — устройства и вёрстка

- [ ] Телефон: полноэкранный режим (п. 1.6.1.1, YG-20).
- [ ] Всё управляется касаниями (п. 1.6.1.5).
- [ ] Нет уведомлений о WebGL (п. 1.6.1.7).
- [ ] Долгое нажатие и правая кнопка не выделяют текст и не открывают меню (п. 1.6.1.8, 1.6.2.7).
- [ ] Компьютер: активная область до края окна и не шире 2:1 — скриншот 2560×1080 (п. 1.6.2.1, 1.6.2.2).
- [ ] Клавиатура только по `event.code`, нет зарезервированных сочетаний: поиск `event.key` и `.key ===` по `src/` (п. 1.6.2.4, 1.6.2.6).
- [ ] Ничего не обрезается и не перекрывается при ресайзе и повороте, нет прокрутки страницы, играется одной рукой — скриншоты QA-04, посмотри каждый (п. 1.8, 1.10).
- [ ] Игра запускается в Chromium, Firefox и WebKit (п. 1.20).

### ads — монетизация

- [ ] Есть реклама или покупки (п. 1.12).
- [ ] Реклама только через SDK: нет своих баннеров, рекламных картинок и имитации блоков (п. 1.16, 4.1, 4.6).
- [ ] Полноэкранная — только сразу после «Дальше» или «В деревню», не позже 2 секунд, начиная с уровня c1-06, не чаще раза в 180 секунд; никогда посреди уровня; рядом с вызовами рекламы нет `setInterval` и таймеров (п. 4.4).
- [ ] Стики-баннер показан только в деревне и скрыт в уровне (YG-12).
- [ ] Река стоит, пока идёт реклама, открыта пауза или вкладка скрыта; после возврата открыто окно «Пауза» (YG-04, YG-05).
- [ ] Rewarded — по кнопке, на которой видно, что будет реклама и что дадут; награда в `onRewarded`; награда — бонус (п. 4.5).
- [ ] После возврата из рекламы состояние игры на месте (п. 4.2).
- [ ] Ориентация рекламных блоков совпадает с ориентацией игры (п. 4.3) — 👤.
- [ ] После покупки «Без рекламы» нет полноэкранной рекламы и стики-баннера.
- [ ] Если `features.iap = true`: консумирование при каждом запуске, название и иконка валюты из SDK, цены цифрами, описание и картинка совпадают с консолью, прогресс в облаке, список товаров совпадает с консолью (п. 1.13).
- [ ] Если `features.iap = false`: в UPLOAD.md сказано, что активных покупок в консоли быть не должно (п. 1.13.6).

### content — содержание и игровой опыт

- [ ] Игра выглядит законченной: нет заглушек, временной графики и отладочных кнопок — скриншоты всех экранов (п. 1.15).
- [ ] Есть счёт, прогресс, цель, нарастающая сложность, больше 10 минут контента (п. 2.4, 2.8, 2.9).
- [ ] Управление описано в игре и в поле «Как играть» (п. 2.2).
- [ ] Язык определяется автоматически; все значимые тексты переведены: проверить `?lang=ru`, `?lang=en`, `?lang=tr` → английский (п. 2.14, 8.2.3).
- [ ] Тексты `ru.json` и `en.json` вычитаны: орфография, пунктуация, без грубых слов (п. 8.2.1, 8.2.4).
- [ ] Нет политики, войн, религии, чёрной магии, реалистичного насилия, предсказаний о здоровье (п. 3.4).
- [ ] Все материалы свои или лицензированы, `CREDITS.md` полон (п. 3.5).
- [ ] Игра не копирует чужую и не дублирует свою (п. 3.6).
- [ ] Нельзя выиграть реальные деньги и призы (п. 3.7).

### promo — промоматериалы (после `/yg-release`)

- [ ] Есть все обязательные поля и файлы: название, «Об игре», «Как играть», категории, иконка, обложка, архив, платформы, ориентация, скриншоты, горизонтальное видео (п. 5.2).
- [ ] Лимиты длины соблюдены, тексты полей не повторяют друг друга, нет «бесплатно», «лучший», «free», «top» (п. 5.3, 5.11, 8.2.2).
- [ ] Название одинаковое в игре, на обложке и в черновике каждого языка; проверена уникальность (п. 5.1.3, 5.12).
- [ ] Иконка и обложка — не скриншоты, без рамок, скруглённых углов и статус-бара (п. 5.6, 8.3.3, 8.3.4).
- [ ] Скриншоты и видео показывают реальный геймплей не меньше 70% (п. 5.1.1.2, 5.1.1.3).
- [ ] Нет артефактов сжатия, одноцветных кадров, обрезанного текста (п. 8.3.1).

### Рекомендации (модерация не проверяет, но они помогают)

- [ ] Почта для обратной связи — в UPLOAD.md (п. 6.1).
- [ ] Кнопка звука, пауза, короткое название без «игра», нет кнопки выхода, обучение, выбор языка с самоназваниями (п. 6.2–6.9).
