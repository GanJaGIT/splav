# Релизный пакет

Результат — папка `release/`, с которой владелец заполняет черновик в консоли Яндекс Игр. Требования к каждому файлу — §9 `docs/TZ.md`.

## Порядок

1. **Предусловия.** `npm run verify` зелёный. Есть отчёт `/yg-audit` за сегодня без ❌ — если нет, запусти `/yg-audit` и исправь найденное.
2. **Версия.** Возьми версию из `package.json`. Если архив с этой версией уже лежит в `release/`, подними последнюю цифру версии.
3. **Архив.** `npm run build`, `npm run zip`, `npm run check:build`.
4. **Промоматериалы.** `npm run promo`:
   - скриншоты: компьютер 1920×1080 и телефон 1080×1920 (окно 360×640 с `deviceScaleFactor: 3`), по 4 штуки, только в уровнях (не деревня и не меню): река течёт, видны предметы, пристани с заказами и счётчик комбо; один кадр — момент слияния со вспышкой;
   - видео 16:9 по сценарию §9: запись Playwright → ffmpeg-static → MP4 H.264, не длиннее 28 секунд; по желанию то же 9:16;
   - иконка 512×512 и обложки 800×470 для ru и en — композиции из SVG игры (лодка на реке, предметы, вспышка слияния), название — как в черновике языка, без рамок и скруглённых углов, не скриншоты.
5. **Проверка файлов.** Скриптом выведи таблицу: файл, размер в пикселях, вес, длительность видео. Сверь с §9. Открой и посмотри каждую картинку и несколько кадров видео: нет обрезанного текста, артефактов и пустых кадров.
6. **Тексты.** Напиши `release/draft-ru.md` и `release/draft-en.md` с полями: название, описание для SEO, «Об игре», короткое описание, «Как играть», ключевые слова, теги, категории. Рядом с каждым полем — число символов, посчитанное скриптом. Проверь лимиты §9 и то, что тексты полей не повторяют друг друга. «Как играть» описывает правила (река несёт предметы, одинаковые сливаются, заказы на пристанях, заводь и потери) и управление на телефоне (протянуть предмет пальцем или коснуться предмета и цели) и на компьютере (то же мышью, Escape — пауза, 1–4 — бустеры).
7. **CREDITS.md.** Все внешние ассеты (шрифт, музыка, если есть) — с источником и лицензией.
8. **UPLOAD.md.** Пошагово для владельца:
   - открыть черновик, загрузить архив;
   - платформы: компьютер, телефоны iOS и Android; ориентация — портретная; языки — ru, en; возрастной рейтинг — 0+; категории и теги — из draft-файлов;
   - отметить «Игра использует облачные сохранения»;
   - заполнить тексты и загрузить материалы для каждого языка;
   - реклама: стики-баннер на телефоне (внизу) и на компьютере, опция «Использовать API для показа sticky-баннера»; автоматический полноэкранный режим;
   - лидерборды `stars` и `daily` (числовые, по убыванию), если ещё не созданы;
   - покупки: если `features.iap = true` — товары `no_ads` и `boosters_10` с теми же названиями, описаниями и картинками, что в игре; если `false` — в консоли не должно быть активных покупок;
   - почта для обратной связи;
   - комментарий для модератора (готовый текст: прогресс сохраняется локально и в облаке сразу после действий; уровень длится 2–4 минуты и после перезагрузки начинается заново, это задумано; полноэкранная реклама — после нажатия «Дальше» в конце уровня, начиная с 6-го уровня; при сворачивании вкладки игра встаёт на паузу);
   - открыть черновик с `&debug-mode=16`, проверить индикатор `IT`, пройти уровни 1–6, проверить звук и паузу при сворачивании вкладки, рекламу после уровня 6, баннер в деревне и его отсутствие в уровне;
   - отправить на модерацию.
9. **Итог владельцу.** Список файлов в `release/` и три следующих действия.
